# 决策启发式（8 条）

> 格式：如果 X，则 Y。每条都有实例；没有实例的不写。

---

**1. 如果一件事需要「定下来」，先问能不能不定。**
买房、买车、长期合约、独家绑定，都会把选择权换成固定成本。他 2016 年的三不主义（30 岁前不买房不买车不结婚）就是这个逻辑的极端版本。
→ 用在 IP 上：不要过早把自己定义为「只做某个垂类」。

**2. 如果两个选项信息量差不多，选那个能产生素材的。**
他的午餐、香蕉、太空，共同点是「能产出全球头条」。判断标准不是「值不值」，是「能不能被讲」。
→ 用在 IP 上：选题优先选「有画面、有数字、有冲突」的。

**3. 如果别人都在劝你别做，先分清是「风险提示」还是「面子压力」。**
他把「被嘲笑」当默认成本：「你一旦练了孙学和薄肌，又帅又有肌肉还有钱，一定会遭到嫉妒」。这条让他能在舆论里不动摇，也让他听不进真正的反对。
→ 用在 IP 上：被骂不一定是错，但「被骂」本身也不证明对。

**4. 如果一件事没有数字，就不要说它成立。**
他的表达里数字密度极高：456.7888 万美元、620 万、75%、29% 体脂、600 亿枚 TRX。
→ 用在 IP 上：文案里没有具体数字，读者就不信。

**5. 如果找不到增量，就去存量里重新分配。**
「不要被现在的存量羁绊，目光要紧盯增量」；反过来，当增量消失时，他的做法是去抢存量里的位置（收购交易所、拿外交身份）。
→ 用在 IP 上：红海赛道不是不能进，但要换一个维度切。

**6. 如果被质疑，先判断对方是在讨论事实还是在讨论动机。**
讨论事实 → 给数据和出处；讨论动机 → 不接，把话题拉回事实。
→ 用在 IP 上：评论区吵架，只回能验证的那一半。

**7. 如果一个方法在 A 领域有效，先假设它在 B 领域也有效，再找反例。**
他把「生物实验」「游戏版本」「软件迭代」的框架搬到人生决策上——大部分是类比，不是论证。
→ 用在 IP 上：跨领域类比很出彩，但要说清「这是类比，不是证据」。

**8. 如果只能记住一句，就记「先自由，后财富」。**
他的版本是：先让自己具备「不为钱出卖时间/注意力/情感/尊严」的能力，财富是伴生物。
→ 用在 IP 上：先做能让你不接烂活的能力，再谈变现；顺序反了，内容会先烂掉。

---

## 使用提示

这 8 条是**判断工具**，不是道德准则。其中第 3、5、6 条有明显的滥用空间（把「被骂」当勋章、把「抢存量」当零和、把「不谈动机」当免责），单独使用时必须配合 `tensions.md` 里的矛盾一起读。
